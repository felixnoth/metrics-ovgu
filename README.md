# Econometrics (Master) — OVGU Magdeburg

Companion repository for the Econometrics course at Otto von Guericke
University Magdeburg, taught by [Felix Noth](https://felixnoth.github.io).
Course page with schedule, readings, and organization:
[felixnoth.github.io/teaching/econometrics-master](https://felixnoth.github.io/teaching/econometrics-master.html).
Textbook: Huntington-Klein (2021), *The Effect* — free at
[theeffectbook.net](https://theeffectbook.net).

## What is here

| Folder | Content |
|--------|---------|
| `intro-to-r/` | The annotated R script for session A1, Introduction to R. Open it in RStudio and run it line by line. |
| `exercises/` | The five exercise sessions (E1–E5) with solutions in R scripts. Posted during the term. |
| `extra-material/` | Additional material on specific problems and issues raised in the course. Grows over the term. |

## Getting started (before session A1)

1. Install R: [cran.r-project.org](https://cran.r-project.org)
2. Install RStudio: [posit.co/download/rstudio-desktop](https://posit.co/download/rstudio-desktop/)
3. In the RStudio console, run once:

   ```r
   install.packages(c("tidyverse", "causaldata"))
   ```

4. Download this repository (green **Code** button → Download ZIP, or
   `git clone https://github.com/felixnoth/metrics-ovgu.git`) and open
   `intro-to-r/intro_to_r.R` in RStudio.

Installation help: Alexander (2023), *Telling Stories with Data*, chapters
A.3.1 and A.3.2 — free at
[tellingstorieswithdata.com](https://tellingstorieswithdata.com).
